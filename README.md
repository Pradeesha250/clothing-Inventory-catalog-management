# Clothing Inventory & Catalog Management Platform

## Project Overview
The Clothing Inventory & Catalog Management Platform is a full-stack web application developed for boutique owners to manage clothing products, categories, inventory, and stock efficiently.

## Features
- User Login
- Dashboard
- Product Management
- Category Management
- Inventory Management
- Search Products
- Low Stock Alerts

## Technology Stack
- Frontend: React.js
- Backend: Spring Boot (Java)
- Database: MySQL
- Version Control: Git & GitHub
